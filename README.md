## About

I write software for a living, but the code I care about most happens after
hours. Backends and systems work go in Rust, frontends in Svelte. Most of what
I build is small, fast, and made for a single job.

## What I enjoy

- **Small, fast binaries.** Programs that start in single-digit milliseconds,
  do their job, and exit without asking anything of you.
- **Terminals.** The one interface that hasn't redesigned itself into
  something worse every eighteen months.
- **Scratching my own itches.** When a tool disappoints me for long enough, I
  write the replacement myself. ghpulse started that way.
- **Systems that fail loudly.** A program that refuses to start beats one that
  quietly does the wrong thing for six weeks.
- **Rust.** The compiler asks the hard questions up front, so the runtime
  doesn't have to. It's my default for anything that matters.
