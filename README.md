## About

I build the things that shouldn't exist, and somehow they compile and persist.
Mostly in Rust, increasingly by describing what I want to a language model and
pushing whatever comes back.

People say you should review AI output carefully. I have heard this. I have not
acted on it. In my defence, this is why I picked Rust: the borrow checker
reviews my pull requests now, and unlike every human reviewer I have worked
with, it has never once said "looks good to me, just a nit."

```
Languages      Rust, and whatever the model was feeling that day
Editor         a terminal. The robot had to come to me.
Methodology    vibes, then push, then read the stack trace
Code review    cargo build
Second review  the issue tracker
Commits        also the robot
Slop output    nominal
```

It writes the code. It writes the commit message describing the code. It runs
the commit. My entire contribution to the software development lifecycle is
pressing `y`.

So the history is clean, the messages are conventional, and `git blame` points
squarely at me. It is lying. It has always been lying.

## What I actually enjoy

- **Small, fast binaries.** Programs that start in single-digit milliseconds,
  do one thing, and exit without asking anything of you.
- **Terminals.** The last interface that never tried to redesign itself into a
  worse version every eighteen months.
- **Rendering things.** Turning data into pictures, usually SVG, usually at
  three in the morning for no commercial reason whatsoever.
- **Systems that fail loudly.** I would rather a program refuse to start than
  quietly do the wrong thing for six weeks.
- **Losing arguments with the borrow checker.** It has never been wrong. I have
  never admitted this out loud until now.
